## Description (EN, ≤ 4000)

Almide Playground is a complete environment for the Almide programming
language, in your pocket and on your desk. Write a program, press Run, and
see what it prints — or what it draws.

- **Real compiler, on the device.** Your code is compiled by the Almide
  compiler itself and runs in a sandbox on your phone, tablet or computer.
  No account, no server round trip.
- **See it, not just read it.** Programs that print SVG, PPM or simple HTML
  show up in the Visual tab: fractals, mazes, generative art, fireworks.
- **Build real GUIs.** Write an app with the ceangal UI framework — the same
  one the playground is built with — and use it right inside the playground.
  The Todo example takes you from code to a working app in one tap.
- **An editor made for code.** Syntax highlighting, errors as you type,
  undo, multiple files per project, Japanese input, light and dark themes,
  and a layout that works with a keyboard or a finger.
- **Learn from examples.** From Hello World to pattern matching, parsers and
  graphics: every example runs as is.
- **Share in one link.** A share link carries your whole project in the
  URL; export a project as a zip that builds with the Almide CLI.
- **AI assistant (bring your own key).** Describe a program and let Claude,
  GPT or Gemini write it; if it fails, the assistant reads the error and
  fixes it. Your key stays in your device's keychain and requests go
  straight to the provider you choose.

Almide is an open-source language designed to be easy for people and for AI
to read and write. Learn more at github.com/almide/almide.

## Description (JA)

Almide Playground は、プログラミング言語 Almide を書いて動かすための環境
です。スマホでもデスクトップでも、コードを書いて Run を押せば、出力も描画も
その場で確かめられます。

- **本物のコンパイラが端末の中で動く。** Almide のコンパイラそのものが
  コードをコンパイルし、端末上のサンドボックスで実行します。アカウントも
  サーバーとの通信も要りません。
- **出力を「見る」。** SVG、PPM、簡単な HTML を出力するプログラムは
  Visual タブに描画されます。フラクタル、迷路、ジェネラティブアート、花火。
- **本物の GUI を作れる。** Playground 自身と同じ UI フレームワーク
  ceangal でアプリを書き、その場で操作できます。Todo の例なら、ワンタップで
  コードから動くアプリまで。
- **コードのためのエディタ。** シンタックスハイライト、入力中のエラー表示、
  undo、複数ファイル、日本語入力、ライト / ダークテーマ。キーボードでも
  指でも使いやすいレイアウトです。
- **例から学ぶ。** Hello World からパターンマッチ、パーサ、グラフィックまで、
  どの例もそのまま動きます。
- **リンク一つで共有。** 共有リンクはプロジェクト全体を URL に含みます。
  Almide CLI でそのままビルドできる zip にも書き出せます。
- **AI アシスタント(自分のキーで)。** 作りたいものを書けば Claude、GPT、
  Gemini がコードを書き、失敗すればエラーを読んで直します。API キーは端末の
  キーチェーンに保存され、リクエストは選んだプロバイダに直接送られます。
